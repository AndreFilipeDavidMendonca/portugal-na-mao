# portugal-workspace

Workspace raiz que agrupa os repositórios do projeto **Portugal na Mão**. Cada subpasta abaixo é um symlink para o repositório real em `~/IdeaProjects/`.

## Repositórios

| Pasta | O que é |
|---|---|
| `portugal-na-mao-api/` | Backend Spring Boot da plataforma (POIs, viagens, motor de recomendação, feed social). Ver o `README.md` desse repositório e `CLAUDE.md` para as regras operacionais. |
| `PT-portugal-na-mao-fe/` | Frontend React (CRA/craco) da plataforma. |
| `pt-operations-api/`, `pt-operations-fe/` | Ferramenta interna de operações (dashboard/explorador de dados, sync local↔produção, auditoria). |
| `portugal-na-palma-da-mao/` | Projeto mais antigo, anterior a esta plataforma — ver README próprio dentro dessa pasta. |

## Documentação

Os ficheiros `.md` soltos na raiz deste workspace e na raiz de `portugal-na-mao-api/` são relatórios/estudos de fases de trabalho anteriores (a maioria de fases já fechadas — ver `FULL_CODEBASE_RESTRUCTURING_AUDIT.md` em `portugal-na-mao-api/` para um inventário e uma proposta de organização em `docs/`).
